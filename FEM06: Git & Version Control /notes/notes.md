## Resource Book

1. 1. What is Version Control? 🤔
Understand why version control is essential for software development and collaboration.

Article: What is version control?

This Atlassian article explains the core concepts of version control, why it's necessary, and the benefits it provides over manually tracking file changes.

Link: https://www.atlassian.com/git/tutorials/what-is-version-control#:~:text=Version
2. 2. Getting Started with Git 🚀
Learn the basic Git commands to initialize a repository, configure your setup, and start tracking changes locally.

Video: Git Explained in 100 Seconds

A rapid-fire introduction to the fundamental concepts and purpose of Git.


Play Video : https://www.youtube.com/watch?v=hwP7WQkmECE 
Article: Git cheat sheet

An invaluable quick reference from GitHub Education covering the most common Git commands for initialization, configuration, staging, committing, and viewing history. Keep this handy!

Link: https://education.github.com/git-cheat-sheet-education.pdf

3. 3. Branching and Merging Workflows 🌳
Master the core workflow of Git: creating branches for new features or fixes and merging them back into the main codebase.

Article: Feature Branch Workflow

This article explains the popular Feature Branch workflow, where each new piece of work is done on a separate branch, keeping the main branch stable.

Link: https://blog.mergify.com/feature-branch-a-quick-walk-through-git-workflow/

Video: Git Workflow

This video likely demonstrates a standard Git workflow, showing how to branch, make changes, commit, and potentially merge or prepare for collaboration.


Play Video: https://www.youtube.com/watch?v=Lj_jAFwofLs
Article: Merging vs. Rebasing

Understand the two primary ways to integrate changes from one branch into another: merging and rebasing, and the pros and cons of each approach.

Link: https://www.atlassian.com/git/tutorials/merging-vs-rebasing

Video: Handling merge conflicts

Merge conflicts happen! This video explains what they are and demonstrates how to resolve common conflicts when Git can't automatically merge changes.


Play Video: https://www.youtube.com/watch?v=Sqsz1-o7nXk

4. 4. Collaborating with GitHub 🤝
Learn how to use GitHub (or similar platforms) to host your remote repositories, back up your work, and collaborate with others using Pull Requests.

Article: Pull Requests and Code Reviews

This GitHub documentation explains the concept of Pull Requests (PRs) – proposing changes from your branch to another – and the process of reviewing code within a PR before merging.

Link: https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/reviewing-changes-in-pull-requests/about-pull-request-reviews 

5. Discussion Prompt
Describe the Feature Branch workflow. Why is it generally preferred over committing directly to the main branch, especially when working in a team?
