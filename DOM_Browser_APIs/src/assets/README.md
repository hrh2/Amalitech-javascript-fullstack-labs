# Logo assets

Replace these two files with your real exported logos — same filenames,
same folder, and everything in the app will pick them up automatically:

- `logo-light.svg` — shown in light mode / on light backgrounds
- `logo-dark.svg` — shown in dark mode / on dark backgrounds (sidebar
  brand mark and the mobile top bar switch to this one automatically
  when Dark Mode is active)

The logo image should already include the "Notes" wordmark — the app
does not render any extra text next to it.
