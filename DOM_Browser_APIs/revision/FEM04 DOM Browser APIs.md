These resources introduce the Document Object Model (DOM) and fundamental manipulation techniques.

https://developer.mozilla.org/en-US/docs/Web/API/Document_Object_Model/Introduction

JavaScript HTML DOM | W3Schools This W3Schools tutorial offers practical examples of how to access and modify HTML elements using JavaScript, covering essential methods for finding and changing DOM nodes. Read the Article
https://www.w3schools.com/js/js_htmldom.asp

3. Exploring Browser APIs (Further Study)
While the provided resources focus heavily on the DOM, encourage learners to explore these crucial Browser APIs mentioned in the objectives using MDN or other reliable sources:

Event Listeners: Learn how to make pages interactive by responding to user actions like clicks, key presses, and mouse movements.

Fetch API: Discover how to request data from servers asynchronously to load new content without refreshing the page.

Web Storage API (localStorage/sessionStorage): Understand how to save user data directly in the browser for persistence across sessions or within a single session.

Browser Rendering: Investigate how browsers parse HTML/CSS and execute JavaScript to display a web page, and how this impacts performance.
4. Discussion Prompt
What are the key differences between localStorage and sessionStorage? Provide a scenario where you would choose one over the other.
