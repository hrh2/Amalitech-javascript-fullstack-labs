# To-Do App (Refactoring for Performance)

Starting point for the FEM19 lab: the provided legacy single-component To-Do app (`src/app/app.ts`, kept unchanged
in `docs/legacy-todo-app.ts`), set up in a fresh Angular project with Tailwind and Jest.

`perf/measure.mjs` measures how much change-detection work a scripted interaction causes;
`perf/results-before.json` is the baseline taken on this legacy code.
